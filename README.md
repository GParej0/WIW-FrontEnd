# Where's Waldo? — A Photo Tagging App

A photo tagging game inspired by *Where's Waldo?*, built as part of The Odin Project curriculum.

## About the Project

**Where's Waldo?** is an interactive photo tagging application where players must find and identify specific characters hidden within a large, detailed image.

The main goal of this project is to practice building interactive web applications, handling user interactions, and working with frontend technologies while following the learning path provided by [The Odin Project](https://www.theodinproject.com/).

## Tech Stack

* React
* TypeScript
* Vite
* Node.js
* HTML5
* CSS3

## Project Status

**In Development**

Current phase: **Frontend development and visual interaction**

The current focus is on building the user interface, implementing image interactions, and creating the core mechanics required for the photo tagging experience.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

Install the project dependencies:

```bash
npm install
```

### Run the Development Server

Start the local development server with:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite in your terminal.
